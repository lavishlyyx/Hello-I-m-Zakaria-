# Portfolio Project Starters

Two linked, independently documented portfolio projects:

1. [SupportSphere Helpdesk](./supportsphere-helpdesk/README.md) — React, TypeScript, FastAPI and SQLite ticket tracker MVP.
2. [Northstar Active Directory Lab](./northstar-ad-lab/README.md) — safe, isolated Windows Server lab with test-user scripts and troubleshooting exercises.

These are **starter projects**, not finished production systems. The web app uses local demo data and is not yet authenticated. Never expose the API to the public internet as-is. Active Directory scripts have **not** been executed against a Windows Server here.

See the respective READMEs for setup steps and completion checklists. The SVGs are illustrative diagrams and mockups, not captured screenshots.
