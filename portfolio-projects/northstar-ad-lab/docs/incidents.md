# Eight practice incidents (to be performed in your own isolated lab)

For each issue, document: ticket ID, symptoms, environment, hypothesis, diagnostic commands, root cause, fix, verification, screenshot evidence and reflection.

1. **INC-001** Account locked: investigate lockout with safe account administration procedures.
2. **INC-002** Share access denied: compare share and NTFS permissions and confirm effective access.
3. **INC-003** DNS failure: set CLIENT01 to an incorrect DNS server, verify `ipconfig /all` and `nslookup`, restore 192.168.50.10.
4. **INC-004** Group Policy not applying: inspect scope, OU placement, `gpresult /r` and event logs.
5. **INC-005** User sign-in fails: check account state and domain controller connectivity.
6. **INC-006** New starter: create approved dummy user and document workstation configuration.
7. **INC-007** Leaver: disable approved dummy account; verify sign-in fails.
8. **INC-008** High resource use: inspect Task Manager, Resource Monitor, and running processes.
