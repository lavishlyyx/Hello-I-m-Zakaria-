# What exists and what still requires a Windows computer

## Available now in GitHub
- Windows Server/Windows 11 lab configuration plan.
- Example PowerShell provisioning script for disabled synthetic test accounts.
- Network topology SVG, incident scenarios and verification checklists.
- A **mock account lookup** in the separate SupportSphere project using fictional records.

## Not completed
- Windows Server VM installation, domain promotion, DNS tests, Windows client domain join.
- Group Policy application, real user account provisioning and screenshot evidence.
- Actual LDAP/Active Directory integration. The web app does not contact Windows Server.

## Verification standard
A real lab can only be marked complete when a technician runs it in an isolated virtual environment, takes screenshots of the domain controller, shows a domain sign-in, verifies group policies, executes diagnostic checks and records results. Do not claim these steps have been completed merely because files exist in GitHub.
