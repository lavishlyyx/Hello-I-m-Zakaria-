# Active Directory hands-on verification checklist

- [ ] Virtualisation support confirmed and sufficient RAM available.
- [ ] Virtual switch isolated from home and workplace networks.
- [ ] Windows Server evaluation VM installed.
- [ ] DC01 assigned the planned static IP and DNS configuration.
- [ ] Domain `ad.northstar.test` created and AD DS health verified.
- [ ] Dummy test accounts created and OU structure checked.
- [ ] Windows 11 test client joined and signed in with a test domain account.
- [ ] `nslookup`, `whoami /groups` and `gpresult /r` recorded.
- [ ] At least five incidents simulated and documented.
- [ ] Screenshots redacted and committed.
- [ ] Optional integration uses least-privileged credentials and is not exposed on the internet.

This checklist is intentionally unchecked until genuine lab execution and evidence exist.
